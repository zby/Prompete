# Wikipedia QA Example

This example demonstrates how to use Prompete with Wikipedia API to create a question-answering system.

## Setup

To run this example, you'll need to install additional dependencies: 

```bash
pip install -r examples/wiki_qa/requirements.txt
```

## Usage

Edit the 'answer.py' script and run it.

The script uses the `ReplayLiteLLM` class to record and later replay the interactions with the LLM.
